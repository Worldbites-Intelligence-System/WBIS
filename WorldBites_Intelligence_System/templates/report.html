1. Introduction

WorldBites Intelligence System is a data analysis web application created to study global events and their possible effect on market assets. It presents cleaned data, statistical summaries, charts, and high-risk alerts through a simple Flask dashboard.

2. Problem Statement

Global events such as conflicts, policy changes, natural disasters, and trade agreements can affect markets in different ways. Raw event data can be difficult to understand without cleaning, scoring, and visual presentation. This project provides a simple system for organizing and analyzing that information.

3. Objectives

  • Load and clean global event data stored in CSV format.
  • Calculate an easy-to-understand risk score for each event.
  • Compare risk and impact across assets, regions, and event types.
  • Create charts that clearly present important patterns.
  • Identify high-risk events using a simple alert condition.
  • Display the results through a professional Flask dashboard.

4. Dataset Description

The project uses a fictional CSV dataset containing {{ data.total_events }} global events. Each row includes the event date, source, title, region, country, event type, affected asset, sentiment score, confidence score, impact score, and severity. The dataset covers {{ data.total_regions }} regions and {{ data.total_assets }} market assets.

5. Tools and Technologies Used

  • Python: Main programming language.
  • Flask: Creates routes and displays web pages.
  • Pandas: Loads, cleans, groups, and summarizes data.
  • NumPy: Calculates weighted risk scores.
  • Matplotlib: Creates and saves charts.
  • CSV: Stores raw, cleaned, and alert data.
  • HTML and CSS: Build and style the dashboard.

6. Methodology

The system follows a clear pipeline: load raw CSV data, clean it with Pandas, calculate risk scores with NumPy, create analytical summaries, generate Matplotlib charts, save high-risk alerts, and display the final results in Flask webpages.

CSV Data → Pandas Cleaning → NumPy Scoring → Pandas Analysis → Matplotlib Charts → Flask Dashboard

7. Data Cleaning Process

Pandas is used to remove duplicate rows, convert the date column to datetime format, remove extra spaces from text, convert score columns to numeric values, and handle missing data. The cleaned result is saved as data/cleaned_events.csv.

8. NumPy Risk Scoring Model

The risk score is calculated using a simple weighted formula. Impact score has the highest weight, confidence score has a medium weight, and the absolute sentiment score has the smallest weight.

Risk Score = (Impact Score × 60%) + (Confidence Score × 100 × 25%) + (|Sentiment Score| × 100 × 15%)

Scores below 50 are Low Risk, scores from 50 to 74 are Medium Risk, and scores of 75 or more are High Risk.

9. Pandas Analysis

Pandas descriptive statistics calculate the mean, median, standard deviation, minimum, and maximum values. The project also uses groupby to compare assets and regions, and value_counts to count event types. The current average risk score is {{ data.average_risk_score }}.

10. Matplotlib Visualizations

Matplotlib creates six charts showing event type counts, average asset impact, average regional impact, risk categories, daily risk trends, and the top high-risk events. The charts are saved as PNG files inside static/charts/ and displayed in the dashboard.

11. Alert System

An event becomes an alert when its risk score is at least 75 and its confidence score is at least 0.70. The current dataset generates {{ alerts|length }} alerts. These rows are saved in data/high_alerts.csv for quick review.

12. Key Insights

  • The dataset contains Low, Medium, and High Risk events.
  • Impact and confidence strongly influence the final risk score.
  • Groupby analysis makes it easy to compare assets and regions.
  • Charts make trends and high-risk events easier to identify.
  • The alert condition filters the most important events for review.

13. Limitations

  • The project uses fictional event data instead of live market data.
  • The risk formula is rule-based and does not predict future prices.
  • Risk weights are fixed and may not suit every real-world situation.
  • The system does not use a database or automatic data updates.

14. Future Scope

Future versions could use verified live data sources, allow users to select custom scoring weights, add more filters, compare longer time periods, and export detailed reports. These improvements can be added gradually while keeping the current system as a clear foundation.

15. Conclusion

WorldBites Intelligence System demonstrates a complete beginner-friendly data analysis workflow. It connects CSV data, Pandas cleaning and analysis, NumPy calculations, Matplotlib charts, and Flask webpages in one project. The result is simple to understand, useful for presentation, and suitable for explaining during a college viva.
