About the Project

WorldBites Intelligence System

A simple data analysis project that turns global event data into useful market-impact summaries, charts, and alerts.

What Is WorldBites Intelligence System?

WorldBites Intelligence System is a Flask-based web application created as a college project. It studies fictional global events such as policy changes, trade agreements, conflicts, natural disasters, and supply disruptions. The system shows how these events may affect assets such as crude oil, gold, shipping, currencies, agriculture, and technology.

How the Project Analyzes Global Events

The project starts by loading event records from a CSV file. It cleans the records, calculates a risk score, creates statistical summaries, generates charts, and identifies high-risk alerts. The final results are displayed on simple dashboard pages that are easy to read and explain.

CSV Data → Data Cleaning → Risk Scoring → Analysis → Charts → Alerts

Relation to My Course

This project brings together important topics from programming, data analysis, statistics, and web development. It demonstrates how Python can solve a practical problem by reading data, processing it, performing calculations, and presenting the results through a web application. Each step is kept simple so it can be clearly discussed during a viva.

How Each Technology Is Used

Each tool has a clear and practical role in the project.

CSV Files

CSV files store the raw events, cleaned events, and high-risk alerts. They make the project data easy to view and share.

Pandas

Pandas loads CSV data into DataFrames, removes duplicates, handles missing values, converts data types, groups records, and calculates descriptive statistics.

NumPy

NumPy helps calculate the weighted risk score and assign Low, Medium, or High Risk categories to each event.

Matplotlib

Matplotlib creates charts for event counts, asset impact, regional impact, risk categories, daily trends, and high-risk events.

Flask

Flask connects the Python analysis to the web pages. Its routes load data and send summaries, tables, charts, and alerts to the correct dashboard pages.

HTML and CSS

HTML creates the page structure, tables, cards, and navigation. CSS gives the dashboard a clean and professional appearance.

Future Improvements

Future versions could use verified live event data, add filters for regions and assets, allow custom risk weights, and create downloadable reports. More charts and longer time-period comparisons could also make the analysis more useful. These features can be added gradually without changing the simple foundation of the project.
